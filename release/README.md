# セッション管理ツール for NovelAI

NovelAI（novelai.net）の**画像生成セッション**を、複製・ZIP保存・取り込み・一覧表示できる Chrome 拡張機能です。
あわせて、保存したZIPから**サムネイル付きの生成台帳（HTML/CSV）**を作るツールも入っています。

制作: だくてん with Claude　／　バージョン 0.3.0　／　**非公式ツール**（NovelAI運営とは無関係です）

---

## 1. 導入（最初の1回だけ）
1. このZIPを**展開**します（ZIPのままでは使えません）。
2. Chromeで `chrome://extensions` を開き、右上の **「デベロッパーモード」** をオンにします。
3. **「パッケージ化されていない拡張機能を読み込む」** を押し、展開したフォルダの中の **`extension` フォルダ** を選びます。
4. 「セッション管理ツール for NovelAI」が一覧に出れば完了です。

※ 展開したフォルダは**消したり移動したりしないでください**（Chromeがそこを読みに行きます）。

## 2. 使い方
1. https://novelai.net/image を開きます（**NovelAIのタブは1つだけ**にしてください）。
2. 「Load a previous session?」（前のセッションを読み込みますか？）の画面が出ると、その右側に**セッション管理パネル**が表示されます。

| ボタン | できること |
|---|---|
| **一覧表示** | 別タブにそのセッションの元画像をギャラリー表示します。クリックで拡大し、プロンプトやシード値を確認・コピーできます（←→キー／Escで操作） |
| **複製** | セッションをそのまま複製します。複製後に**ページを再読み込み**すると、上のセッション一覧に増えます |
| **ZIP保存** | セッションを画像ごとZIPファイルに保存します（バックアップ・持ち運び用） |
| **取り込み**（パネル右上） | 「ZIP保存」で作ったZIPを、新しいセッションとして取り込みます。元のセッションは上書きされません |

- 複製や取り込みで増えたセッションは、NovelAI標準の「削除」ボタンで消せます。
- 「一覧表示」のタブは、**元のNovelAIタブを閉じたり再読み込みしたりすると画像が見えなくなります**。残したいときは下の台帳ツールを使ってください。
- 画像データが残っていない古いセッションは、サムネイルだけの表示になります。

## 3. 生成台帳ツール（`ledger` フォルダ）
1. `ledger/session-ledger.html` を Chrome で開きます（ダブルクリックでOK）。
2. 「ZIP保存」で作ったZIPを、画面にドラッグ＆ドロップします（複数可）。
3. 「HTML台帳を保存」または「CSVを保存」を押します。
   - **HTML**: サムネイル付き。プロンプトをクリックでコピー、検索で絞り込みもできます。
   - **CSV**: Excelなどで開けます。

通信は一切せず、データはこのPCの外に出ません。

## 4. 注意
- **自己責任でお使いください。** NovelAI側の内部仕様が変わると、動かなくなったり、複製が読めなくなったりする可能性があります。
- 大事なセッションは、複製や取り込みの前に **「ZIP保存」でバックアップ**しておくと安心です。
- NovelAIのタブを複数開いていると、保存内容が上書きされることがあります。操作は1タブで行ってください。
- この拡張機能は外部と通信しません。ブラウザに保存されたセッションを、ブラウザ内で読み書きするだけです。
- ZIPや台帳には**プロンプトやシード値が入っています**。他の人に渡すときはご注意ください。

## 5. 更新・削除
- **更新**: 新しいバージョンのZIPを展開し、同じ場所に上書きしてから、`chrome://extensions` でこの拡張機能の「再読み込み」（円形の矢印）を押します。
- **削除**: `chrome://extensions` でこの拡張機能の「削除」を押します。保存済みのセッションは消えません。
